# เครื่องมือปรับตำแหน่งสำหรับ Admin

แพตช์อยู่ใน branch `hotfix/signature-placement` แยกจากชุดปรับปรุงระบบใหญ่ ยังไม่ deploy ขึ้น PRD

## วิธีใช้งาน

1. เปิดปรับตำแหน่งของคำร้องที่ต้องการ แล้วเลือกองค์ประกอบจากหน้าเอกสารหรือรายการด้านบน
2. ลากเพื่อจัดคร่าว ๆ จากนั้นกรอก X/Y เป็นมิลลิเมตร วัดจากมุมซ้ายบนกระดาษ กด Enter หรือออกจากช่องกรอกเพื่อใช้ค่า
3. ใช้ปุ่มลูกศรเลื่อนครั้งละ 0.1 มม. หรือ Shift + ลูกศรครั้งละ 1 มม. ปุ่มลูกศรจะไม่ขยับองค์ประกอบระหว่างกำลังพิมพ์ข้อความ
4. ซูม 50–200% เพื่อเล็งตำแหน่ง และเปิดเส้นช่วยวางทุก 5 มม. ได้ ระยะที่บันทึกอ้างอิงกระดาษ ไม่เปลี่ยนตามการซูม
5. ใช้ Undo/Redo ย้อนการลาก การปรับขนาด ข้อความ หรือการเพิ่ม/ลบองค์ประกอบ โดยการลากหนึ่งครั้งนับเป็นประวัติหนึ่งรายการ
6. ตรวจหน้าเอกสารให้ถูกต้องก่อนบันทึก หากเลือกหน้าที่ไม่มีอยู่ ระบบจะให้แก้ก่อนบันทึก

## การบันทึก

- ปรับเฉพาะคำร้องที่เปิดอยู่ เพราะไฟล์แต่ละฉบับอาจมีตำแหน่งช่องลงนามต่างกัน
- ใช้ไฟล์ต้นฉบับจริงในการสร้างเอกสารที่ปรับใหม่ ไม่ใช้แบบเปล่ามาแทนเมื่อเปิดต้นฉบับไม่ได้
- หากมีคนอื่นแก้คำร้องระหว่างเปิดหน้าปรับตำแหน่ง ระบบจะปฏิเสธการทับเวอร์ชันใหม่และให้โหลดคำร้องใหม่
- กรณีสร้าง PDF อัปโหลด หรือบันทึกไม่สำเร็จ จะคงหน้าปรับตำแหน่งไว้และไม่แจ้งว่าสำเร็จ
- ชุดโค้ดนี้ไม่ได้แก้สถานะอนุมัติหรือผู้อนุมัติ และไม่ได้ส่งการแจ้งเตือนจากการบันทึกตำแหน่ง
